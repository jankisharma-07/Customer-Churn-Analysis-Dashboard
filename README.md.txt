# Customer Churn Analysis Dashboard

An interactive Power BI dashboard developed to analyze customer churn patterns and understand factors associated with customer retention.

This project was created as a practical data analytics project to strengthen my skills in SQL, Microsoft Excel, Power BI, data cleaning, data analysis, and data visualization.

## 📊 Dashboard Overview

The dashboard provides an interactive view of customer churn through:

- Total Customers
- Churned Customers
- Churn Rate
- Retention Rate
- Churn by Contract Type
- Churn by Customer Tenure
- Churn by Payment Method
- Churn by Internet Service
- Interactive filters for customer segmentation

## 🛠️ Tools & Technologies

- SQL / MySQL
- Microsoft Excel
- Power BI
- Data Cleaning
- Exploratory Data Analysis
- Data Visualization

## 🔄 Project Workflow

1. Cleaned and prepared the customer dataset using Microsoft Excel.
2. Imported the cleaned data into MySQL for analysis.
3. Used SQL queries to explore customer information and identify churn patterns.
4. Created calculated metrics such as total customers, churned customers, churn rate, and retention rate.
5. Built an interactive Power BI dashboard using KPI cards, charts, and slicers.
6. Used customer segments such as contract type, tenure, payment method, and internet service to understand churn patterns.
7. Exported the final dashboard as a PDF for reporting and presentation.

🎯 Key Objective

The main objective of this project is to analyze customer churn and understand how different customer and subscription characteristics are associated with churn.

The analysis focuses on factors such as:

Contract Type
Customer Tenure
Payment Method
Internet Service

The dashboard also allows users to interactively filter the data and explore customer churn from different perspectives.

📌 Key Insights
Month-to-month customers show higher churn compared with customers on longer-term contracts.
Customers with shorter tenure show a higher tendency to churn.
Churn patterns vary across different payment methods.
Churn also differs across internet service categories.
Interactive Power BI filters make it easier to explore specific customer segments.
